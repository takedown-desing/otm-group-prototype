# ОТМ Групп (otm-group.ru): исследование конкурентов и прототипы

Прототипы главной страницы, каталога и карточки товара по коммерческому предложению «Комплексная переработка сайта otm-group.ru и интеграция B2B-инструментов». Сначала исследование, потом прототип.

**Смотреть прототипы:** https://takedown-desing.github.io/otm-group-prototype/

**Обоснование блоков со скриншотами конкурентов:** https://takedown-desing.github.io/otm-group-prototype/rationale.html

## Пометки на блоках

Каждый блок в прототипах подписан ярлыком в левом верхнем углу:

* серый «Существующий блок»: есть на сайте сейчас, переработан;
* синий «Новый блок: по КП»: описан в коммерческом предложении;
* зелёный «Новый блок: по результатам исследования»: добавлен после разбора конкурентов и спроса.

Кнопка «Скрыть пометки» в верхней панели убирает ярлыки, чтобы смотреть прототип как обычный сайт.

## Как проводилось исследование

1. Полный обход otm-group.ru: 241 URL из sitemap, меню и найденных ссылок. Разобраны блоки главной, 25 разделов каталога, 208 карточек товара, служебные страницы.
2. Спрос по Иркутску: Яндекс Wordstat API, регион 63, плюс парсинг хвостов через Arsenkin.
3. Выдача: Arsenkin check-top (Яндекс, регион Иркутск, 15 запросов, ТОП-10) и Ahrefs SERP overview (Google).
4. Метрики конкурентов: Ahrefs batch analysis (DR, трафик, ссылки), Arsenkin iks (ИКС, отзывы в Яндексе), Keys.so (видимость, конкуренты по пересечению, ключи).
5. Блоки конкурентов: Firecrawl по главным, листингам и карточкам absolutsib.com, vitrinairk.ru, mto38.ru, otilos.ru, westcom.ru, sp-oborudovanie.ru, irkutsk.tdo.ru, irkutsk.trapeza.ru, irkutsk.mr-66.ru, amtcompany.ru, плюс скриншоты Playwright.

Подробности и таблицы в `research/RESEARCH.md`.

## Главные выводы

* 192 из 208 товаров без цены, фильтров и хлебных крошек нет, кейсов и отзывов нет.
* По запросу «торговое оборудование иркутск» сайта нет в ТОП-10 Яндекса, 10 место в Google. Лидер vitrinairk.ru присутствует в 9 из 15 проверенных ТОП-10.
* Семантика смешана с B2C (кухни, шкафы-купе): разделение «Для бизнеса / Для дома» подтверждено данными.
* Страницы «О компании», «Портфолио», «Блог», «Новости» содержат демо-текст шаблона.
* У всех конкурентов есть цены, проекты и мессенджеры. Ни у одного местного нет готовых комплектов под нишу и FAQ для закупщика, это точки отстройки.

## Допущения

* Цены «от», цены дополнений, состав комплектов, число проектов и срок гарантии в прототипе условные и помечены как заполняемые данными клиента.
* Логотипы ТЦ и клиентов заменены плашками.
* Фото объектов заменены рендерами товаров с текущего сайта.
* Адрес производства на сайте отсутствует, в прототипе стоит пометка «уточнить у клиента».

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер в корне репозитория:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080/.
